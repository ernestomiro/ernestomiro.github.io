# Manrope local

`manrope-latin-wght-normal.woff2` es el subconjunto latino variable de
Manrope usado por el portafolio para los pesos `400` a `700`.

- Familia: Manrope.
- Diseñador registrado por Google Fonts: Mikhail Sharanda.
- Licencia: SIL Open Font License 1.1; ver `OFL.txt`.
- Origen del binario: CSS oficial de Google Fonts para Manrope, revisión de
  servicio `v20`, consultado el 2026-08-24.
- URL de procedencia:
  `https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2`.
- Metadatos de Google Fonts: eje `wght` original de `200` a `800`, fuente
  registrada desde el commit
  `6f81ebecdf65e4463b798cc07b16a4f8d5216917`.

El producto limita deliberadamente el rango declarado a `400 700`. No se
consulta Google Fonts durante la ejecución ni se añade un paquete npm.
